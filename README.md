# CodeAlpha CGPA Calculator

A professional C++ based CGPA Calculator developed for the CodeAlpha C++ Programming Internship — Task 1.

## 📌 Project Overview

The CGPA Calculator is a console-based C++ application that calculates a student's semester CGPA and overall CGPA based on course grades and credit hours.

## ✨ Features

- Enter number of courses
- Enter course names
- Enter credit hours
- Enter grades
- Automatically calculate grade points
- Calculate total credit hours
- Calculate total grade points
- Calculate semester CGPA
- Enter previous semester records
- Calculate overall CGPA
- Display individual course results
- Display academic performance
- Input validation

## 🧮 Grade System

| Grade | Grade Point |
|-------|-------------|
| A     | 4.00        |
| B     | 3.00        |
| C     | 2.00        |
| D     | 1.00        |
| F     | 0.00        |

## 📐 CGPA Formula

CGPA is calculated using:

**CGPA = Total Grade Points / Total Credit Hours**

Where:

**Total Grade Points = Credit Hours × Grade Point**

## 🛠️ Technologies Used

- C++
- Structures
- Vectors
- Functions
- Loops
- Conditional Statements
- Input Validation

## ▶️ How to Run

1. Download or clone this repository.
2. Open `CGPA_Calculator.cpp` in a C++ compiler.
3. Compile the program.
4. Run the executable.
5. Enter the required course information.
6. View the calculated CGPA and academic performance.
